# Rust LLM proxy

Date: 2026-10-20

Implemented the initial service from an empty repository. API adapters share a provider-independent gateway and routing policy. Codex uses direct subscription OAuth/HTTP; Claude uses an isolated print-mode subprocess. Accounts own tokens, CIDRs, and multiple provider instances, including instances of the same kind.

PostgreSQL retains request metadata and token counts, with provider statistics derived from those records. Request/response bodies are JSON stdout logs. No administration CLI or dashboard was requested; setup uses SQL and typed server configuration.

See the [PRD](../forge/20261020-llm-proxy/prd.md), [architecture](../forge/20261020-llm-proxy/architecture.md), and [final report](../forge/20261020-llm-proxy/final-report.md) for scope, review decisions, validation, and remaining protocol/deployment limits.
